title: "Foundry VTT"
---

We will be playing on **Foundry Virtual Tabletop**, an open source game software that has a bunch of built-in features for multiple games and a lot of official support for D&D 5e. This is because of how easy it is to customize compared to Roll20, and it also has a bunch of really cool features for immersive gameplay. I've already added a bunch of custom stuff for the Cyberpunk campaign, including Cyberpunk-specific weapons, armor, and equipment. I have also written some useful macros to work with the custom rules for this campaign.

To join, follow these steps:

1. Create a [Forge account](https://forge-vtt.com/account/signup). My Foundry server is hosted on a service called **The Forge**. In order to join, you must first create a free Forge Account to join the Foundry server.  
2. Use the invite link I'll send you privately. This will allow you to join the game with your Forge account.  
3. You can join the game at any time the server is running using the game URL, which I'll also send you privately.

When you reach the "Join Game Session" page, find your name in the "Select User" dropdown, and **do not enter a password**. Click the "Join Game Session" button, and you're in!
