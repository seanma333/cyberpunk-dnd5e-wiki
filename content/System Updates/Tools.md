---
title: "Tools"
---

Artisans and trades in the Cyberpunk world are very different from the ones in core D&D. As such, there are new tools added to the tool list. Furthermore, having proficiency with tools is much more important in the Cyberpunk setting, since tool proficiencies also represent a character's knowledge and intuition about technology. **The standard tools in core D&D still exist and have the same cost and weight.**

Each tool has a typically associated ability, though these are not the only abilities to use with these tools.
